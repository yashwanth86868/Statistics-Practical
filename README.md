# Statistics Practical

## About

This project demonstrates basic statistical analysis using Python on a sales dataset.

## Topics Covered

* Data Creation
* Descriptive Statistics
* Mean, Median & Mode
* Variance & Standard Deviation
* Confidence Interval
* Hypothesis Testing
* Data Visualization

## Tools Used

* Python
* Pandas
* NumPy
* SciPy
* Matplotlib
* Seaborn

## Dataset

The project uses a sample sales dataset containing:

* Product
* Category
* Units Sold
* Sales Date
